# DE-ViT (Deformation-Equivariant Visual Transformer) — детекция крон, теней и сегментация крыш

Модель DE-ViT предназначена для многозадачного анализа аэроснимков: детекции крон деревьев и их теней, регрессии ограничивающих рамок, оценки солнечного азимута и семантической сегментации типов поверхности крыши. 

[Геометрическая интерпретация постановки задачи](images/crown_shadow.pdf)

Архитектура основана на иерархическом визуальном трансформере с деформируемым вниманием, раздельными полями смещения для крон и теней, модулем геометрии крыши и механизмом перекрёстного внимания с геометрическим приором.

## Обучение

Двухстадийное обучение:

**Стадия 1: Предобучение backbone на OAM-TCD**
```bash
python devit/train.py \
  --data-root ./data/oam-tcd \
  --output-dir ./outputs/stage1 \
  --epochs 50 \
  --batch-size 16 \
  --lr 1e-4 \
  --stage pretrain \
  --tasks detection
```

**Стадия 2: Донастройка на комбинированном датасете**
```bash
python devit/train.py \
  --data-root ./data \
  --output-dir ./outputs/stage2 \
  --epochs 100 \
  --batch-size 8 \
  --lr 1e-4 \
  --stage finetune \
  --tasks detection segmentation azimuth roof \
  --resume ./outputs/stage1/best_model.pth
```

Параметры:
- `--data-root`: Путь к данным
- `--output-dir`: Директория для чекпоинтов и логов
- `--epochs`: Количество эпох обучения
- `--batch-size`: Размер батча
- `--lr`: Начальный learning rate (AdamW, косинусный планировщик)
- `--stage`: Этап обучения (`pretrain` или `finetune`)
- `--tasks`: Список задач (`detection`, `segmentation`, `azimuth`, `roof`)
- `--resume`: Путь к чекпоинту для продолжения обучения

## Инференс

```bash
python devit/inference.py \
  --checkpoint ./outputs/stage2/best_model.pth \
  --image ./test_image.png \
  --output-dir ./results \
  --sun-azimuth 2.356 \
  --gsd 0.15 \
  --vis-fields
```

Параметры:
- `--checkpoint`: Путь к чекпоинту модели
- `--image`: Путь к изображению или директории
- `--output-dir`: Директория для результатов
- `--sun-azimuth`: Азимут солнца (радианы). *Примечание: модель использует только направление лучей, высота солнца не требуется.*
- `--gsd`: GSD снимка (м/пиксель)
- `--vis-fields`: Визуализировать поля деформации $\Delta_{tree}$ и $\Delta_{shadow}$

## Ключевые компоненты

### Архитектура Backbone
| Этап | Размер выхода | Блоки | Тип внимания | Поле деформации |
|------|---------------|-------|--------------|-----------------|
| 1 | $H/4 \times W/4 \times 64$ | 2 | Жёсткое оконное | Нет |
| 2 | $H/8 \times W/8 \times 128$ | 2 | Локальное деформируемое | $\Delta_{tree}$ |
| 3 | $H/16 \times W/16 \times 256$ | 4 | Полное деформируемое | $\Delta_{tree}, \Delta_{shadow}$ |
| 4 | $H/32 \times W/32 \times 512$ | 2 | Глобальное деформируемое | $\Delta_{tree}, \Delta_{shadow}$ |

### Деформируемое внимание
- Раздельные поля смещения: 
  - $s_{tree} = 0.15$ (плавные деформации крон)
  - $s_{shadow} = 0.45$ (резкие изломы теней на крышах)
- Билинейная семплировка для субпиксельной точности
- Модуляция по типу поверхности: $\Delta_{shadow}$ корректируется для коньков и скатов через эмбеддинг $R(p)$

### Перекрёстное внимание
- Связывание крон с тенями через геометрический приор
- Кодирование азимута солнца: $PE(\theta_{sun})$
- Учёт глобального контекста освещения сцены

### Функция потерь
$$
\mathcal{L}_{total} = \mathcal{L}_{det} + 0.05 \cdot \mathcal{L}_{def} + 0.5 \cdot \mathcal{L}_{cross} + 0.2 \cdot \mathcal{L}_{roof} + 0.3 \cdot \mathcal{L}_{connect}
$$

Компоненты:
- $\mathcal{L}_{det}$: Focal Loss + L1 bbox + GIoU (детекция объектов)
- $\mathcal{L}_{def}$: Регуляризация градиентов полей смещения (норма Фробениуса)
- $\mathcal{L}_{cross}$: Согласованность «крона–тень» (коллинеарность вектора смещения азимуту солнца)
- $\mathcal{L}_{roof}$: Двусторонняя регуляризация градиентов на коньках (τₘᵢₙ = 0.3, τₘₐₓ = 1.5)
- $\mathcal{L}_{connect}$: Бинарная кросс-энтропия для связности фрагментов теней (Pairwise Link MLP)

### Метрики качества
- mAP@0.5 и mAP@0.5:0.95 (на основе Rotated IoU)
- False Positive Rate (FPR) $\downarrow$
- False Negative Rate (FNR) $\downarrow$
- Доля разрывов теней $\downarrow$
- Доверительные интервалы 95% (bootstrap, 1000 выборок)

## Теоретические свойства

### Приближённая локальная деформационная эквивариантность

Архитектура DE-ViT гарантирует, что для любой гладкой деформации $T$ выполняется соотношение $F(T(I)) \approx T_*(F(I)) + R_L$ с точностью до ошибки интерполяции первого порядка. Это достигается за счёт:

- Преобразования поля смещения как тензора (через якобиан деформации)
- Использования деформированных относительных координат в $PE(\theta_{sun})$
- Билинейной семплировки признаков

## Датасеты

Обучение и валидация проводятся на комбинации датасетов:

1. **OAM-TCD**: 5 072 изображения, 280 000+ размеченных крон
   - Предобучение backbone для детекции крон
   - [Ссылка на датасет](https://zenodo.org/records/11617167)

2. **ISPRS Vaihingen**: 16 изображений высокого разрешения
   - Сегментация крыш и типов поверхностей
   - Оценка устойчивости к теневым артефактам

3. **Синтетические данные**: 1 200 изображений (Unreal Engine 5 + Colosseum)
   - Генерация теней на основе физической модели проекции
   - Параметрические 3D-модели крон (SpeedTree), адаптивное гауссовское размытие (penumbra)

4. **Ciyutuo Village (Расширенная тестовая выборка)**: 65 полноформатных сцен
   - Исходные 13 изображений + 52 дополнительно размеченных сцены (Калужская и Московская области)
   - Суммарно 3 847 размеченных объектов (2 156 крон и 1 691 тень)
   - [Ссылка на исходный датасет](https://www.geodoi.ac.cn/WebEn/doi.aspx?Id=3607)

## Результаты

### Сравнение точности детекции (mAP@0.5 $\uparrow$)

| Модель | Кроны | Тени (плоские) | Тени (скатные крыши) | Среднее |
|---|---|---|---|---|
| YOLO26 | 0.731 | 0.652 | 0.499 | 0.627 |
| RT-DETR | 0.745 | 0.663 | 0.512 | 0.640 |
| Deformable DETR | 0.752 | 0.672 | 0.534 | 0.653 |
| DINO | 0.763 | 0.679 | 0.556 | 0.666 |
| Co-DETR | 0.758 | 0.674 | 0.548 | 0.660 |
| **DE-ViT** | **0.768** | **0.689** | **0.612** | **0.690** |

**Ключевой результат:** выигрыш **+11.3 п.п.** по сравнению с YOLO26 и **+7.8 п.п.** по сравнению с Deformable DETR на самом сложном подклассе (тени на скатных крышах).

## Требования к оборудованию

- GPU: 1× NVIDIA A100 (80 ГБ) или аналог
- Время обучения: ~11 часов (100 эпох, стадия 2)
- Размер входа: $1024 \times 1024$ пикселей
- Оптимизатор: AdamW, начальный lr $10^{-4}$, косинусный планировщик
- Фреймворк: PyTorch 2.0+
