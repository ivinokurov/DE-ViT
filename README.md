# DE-ViT (Deformation-Equivariant Visual Transformer) — детекция крон, теней и сегментация крыш

Модель DE-ViT предназначена для многозадачного анализа аэроснимков: детекции крон деревьев и их теней, регрессии ограничивающих рамок, оценки солнечного азимута и семантической сегментации типов поверхности крыши. 

[Геометрическая интерпретация постановки задачи](images/crown_shadow.pdf)

Архитектура основана на иерархическом визуальном трансформере с деформируемым вниманием, раздельными полями смещения для крон и теней, модулем геометрии крыши и механизмом перекрёстного внимания с геометрическим приором.

[Схема архитектуры](images/architecture.pdf)

## Обучение

Двухстадийное обучение:

**Стадия 1: Предобучение backbone на OAM-TCD**
```bash
python divit/train.py \
  --data-root ./data/oam-tcd \
  --output-dir ./outputs/stage1 \
  --epochs 50 \
  --batch-size 16 \
  --lr 1e-4 \
  --stage pretrain \
  --tasks detection
```

**Стадия 2: Донастройка на комбинированном датасете**
```bash
python divit/train.py \
  --data-root ./data \
  --output-dir ./outputs/stage2 \
  --epochs 100 \
  --batch-size 8 \
  --lr 1e-4 \
  --stage finetune \
  --tasks detection segmentation azimuth roof \
  --resume ./outputs/stage1/best_model.pth
```

Параметры:
- `--data-root`: Путь к данным
- `--output-dir`: Директория для чекпоинтов и логов
- `--epochs`: Количество эпох обучения
- `--batch-size`: Размер батча
- `--lr`: Начальный learning rate
- `--stage`: Этап обучения (`pretrain` или `finetune`)
- `--tasks`: Список задач (`detection`, `segmentation`, `azimuth`, `roof`)
- `--resume`: Путь к чекпоинту для продолжения обучения

## Инференс
```bash
python divit/inference.py \
  --checkpoint ./outputs/stage2/best_model.pth \
  --image ./test_image.png \
  --output-dir ./results \
  --sun-azimuth 2.356 \
  --sun-elevation 0.785 \
  --gsd 0.15 \
  --vis-fields
```

Параметры:
- `--checkpoint`: Путь к чекпоинту модели
- `--image`: Путь к изображению или директории
- `--output-dir`: Директория для результатов
- `--sun-azimuth`: Азимут солнца (радианы)
- `--sun-elevation`: Высота солнца (радианы)
- `--gsd`: GSD снимка (м/пиксель)
- `--vis-fields`: Визуализировать поля деформации $\Delta_{tree}$ и $\Delta_{shadow}$

## Ключевые компоненты

### Архитектура Backbone
| Этап | Размер выхода | Блоки | Тип внимания | Поле деформации |
|------|---------------|-------|--------------|-----------------|
| 1 | H/4 × W/4 × 64 | 2 | Жёсткое оконное | Нет |
| 2 | H/8 × W/8 × 128 | 2 | Локальное деформируемое | $\Delta_{tree}$ |
| 3 | H/16 × W/16 × 256 | 4 | Полное деформируемое | $\Delta_{tree}$, $\Delta_{shadow}$ |
| 4 | H/32 × W/32 × 512 | 2 | Глобальное деформируемое | $\Delta_{tree}$, $\Delta_{shadow}$ |

### Деформируемое внимание
- Раздельные поля смещения: 
  - $s_{tree} = 0.15$ (плавные деформации крон)
  - $s_{shadow} = 0.45$ (резкие изломы теней на крышах)
- Билинейная семплировка для субпиксельной точности
- Модуляция по типу поверхности: $\Delta_{shadow}$ корректируется для коньков и скатов

### Перекрёстное внимание
- Связывание крон с тенями через геометрический приор
- Кодирование азимута солнца: $PE(\theta_{sun})$
- Учёт глобального контекста освещения сцены

### Функция потерь

$$
L_{total} = L_{det} + 0.05 \cdot L_{def} + 0.5 \cdot L_{cross} + 0.2 \cdot L_{roof} + 0.3 \cdot L_{connect}
$$

Компоненты:

- $L_{det}$: Focal Loss + $L_1$ bbox + GIoU (детекция объектов)
- $L_{def}$: Регуляризация градиентов полей смещения (норма Фробениуса)
- $L_{cross}$: Согласованность «крона–тень» с проекцией солнца
- $L_{roof}$: Hinge loss для градиентов на коньках крыш ($\tau_{ridge} = 0.5$)
- $L_{connect}$: Бинарная кросс-энтропия для связности фрагментов теней

### Метрики качества
- mAP@0.5 и mAP@0.5:0.95
- False Positive Rate (FPR)
- False Negative Rate (FNR)
- Доверительные интервалы 95% (bootstrap, 1000 итераций)

## Теоретические свойства

### Приближённая локальная деформационная эквивариантность
Архитектура DE-ViT гарантирует, что для любой гладкой деформации $T$:

$$
F(T(I)) \approx T_*(F(I))
$$

с точностью до ошибки интерполяции первого порядка. Это достигается за счёт:
- Преобразования поля смещения как тензора
- Использования деформированных относительных координат в $PE$
- Билинейной семплировки признаков

## Датасеты

Обучение и валидация проводятся на комбинации трёх датасетов:

1. **OAM-TCD**: 5,072 изображения, 280,000+ размеченных крон
   - Предобучение backbone для детекции крон
   - [Ссылка на датасет](https://zenodo.org/records/11617167)

2. **ISPRS Vaihingen**: 16 изображений высокого разрешения
   - Сегментация крыш и типов поверхностей
   - Оценка устойчивости к теневым артефактам
   - [Ссылка на датасет](https://www.isprs.org/resources/datasets/benchmarks/urbansemlab/2d-sem-label-vaihingen.aspx)

3. **Ciyutuo Village**: 65 изображений коттеджного типа
   - 20% с ручной разметкой теней (тестовая выборка)
   - Целевая настройка для пар «крона–тень»
   - [Ссылка на датасет](https://www.geodoi.ac.cn/WebEn/doi.aspx?Id=3607)
